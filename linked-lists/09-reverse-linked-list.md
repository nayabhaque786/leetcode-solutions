## Problem: Reverse a Linked List (Easy–Medium, Bonus)
**Link:** https://leetcode.com/problems/reverse-linked-list/

### Approach
I iteratively reversed the pointers of each node until the list was fully reversed.

### Complexity
- Time: O(n)
- Space: O(1)

### Notes
Edge case: empty list or single node list.  
Alternative: recursive approach is elegant but uses O(n) space.
