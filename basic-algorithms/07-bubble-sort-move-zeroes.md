## Problem: Bubble Sort Variant / Move Zeroes (Easy–Medium)
**Link:** https://leetcode.com/problems/move-zeroes/

### Approach
I shifted non-zero elements forward and moved zeros to the end. This is more efficient than repeatedly swapping.

### Complexity
- Time: O(n)
- Space: O(1)

### Notes
Edge case: all elements are zero.  
Bubble sort variant is less efficient but good for practice.
